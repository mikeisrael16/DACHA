# Ярославль: Моя дача

Дачный симулятор в духе Township от **Mikhail Game Studio**. Вся игра — один файл `index.html`, работает в браузере на телефоне и компьютере.

## Как играть
Открой `index.html` (или GitHub Pages этого репозитория). Прогресс сохраняется автоматически в браузере.

## Что есть
- Обучение с Татьяной: вскопать → посадить → полить → удобрить → собрать → продать → купить семена
- Рост в реальном времени (грядки растут, даже когда игра закрыта), смена дня и ночи по часам устройства
- 17 культур, открываются по уровням: картофель, морковь, лук, редис, свёкла, укроп, салат, капуста, чеснок, петрушка, огурцы, кабачки, горох, томаты, перец, баклажаны, тыква
- До 3 грядок (вторая — 40 монет, третья — с 6 уровня) и теплица с 5 уровня: плёночная → поликарбонатная → стеклянная (быстрее, без вредителей и воров, стеклянная даёт двойной урожай)
- Летняя кухня с 4 уровня — заготовки из овощей: набор для борща, кабачковая икра, весенний салат, хрустящие соленья, дачное лечо
- С 4 уровня воришки уносят урожай, который долго не собирали; защищают камера наблюдения и высокий забор
- С 5 уровня: вороны (прогнать нажатием или пугалом на 12 часов) и вредители — тля, колорадский жук, слизни (своя отрава для каждого или профессиональная обработка)
- Улучшения инструментов, бочки, заказы соседей, задания, музыка

## Сохранения
Прогресс хранится в браузере под ключом `yaroslavl_dacha_save`. Функция `migrate()` дополняет старые сохранения новыми полями, поэтому обновления не стирают прогресс игроков — при добавлении новых полей достаточно добавить их в `newState()`.

## Разработка
Исходник — `src/game.html` (картинки подставляются вместо меток `__IMG_имя__`), картинки — `src/assets/`.
Собрать `index.html`:

```bash
python3 tools/build.py src/game.html src/assets index.html
```
