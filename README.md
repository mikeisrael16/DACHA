# Ярославль: Моя дача

Дачный симулятор в духе Township от **Mikhail Game Studio**. Вся игра — один файл `index.html`, работает в браузере на телефоне и компьютере.

## Как играть
Открой `index.html` (или GitHub Pages этого репозитория). Прогресс сохраняется автоматически в браузере.

## Что есть (v1.0 «Новая дача»)
- Большой участок у Волги: двигать пальцем, приближать щипком или кнопками
- Грядки и теплицы ставишь сам — вдоль или поперёк, можно переставлять
- 37 овощей и зелени, 10 ягодных кустов и 10 фруктовых деревьев (многолетние)
- Коровы и овцы, сыроварня и прядильня, летняя кухня с заготовками, вареньем и комбикормом
- Скупщик покупает всё и всегда, ежедневный подарок за вход (7 дней, сундук), страховка от нуля монет
- Кот с 5 уровня: имя, корм и вода каждый день
- Вороны и пугало, вредители и средства, воришки, камера и высокий забор
- Порча свежих продуктов через 6 часов, динамические задания, усложнение с 10 уровня
- Окно «Что нового» после каждого обновления, обучение для каждой новой механики
- Пропуск обучения при новой игре — старт с 5 уровня

## Сохранения
Прогресс хранится в браузере под ключом `dacha_v1_save` (v1.0 начинается заново). Функция `migrate()` дополняет старые сохранения новыми полями, поэтому обновления не стирают прогресс игроков — при добавлении новых полей достаточно добавить их в `newState()`.

## Разработка
Собрать `index.html`:

```bash
python3 tools/build.py
```
Исходники: `src/*.js`, `src/body.html`, `src/*.css`, картинки — `src/assets/`. Описание обновления для игроков — массив `CHANGES` в `src/game9.js`.
