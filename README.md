# Ярославль: Моя дача

Дачный симулятор в духе Township от **Mikhail Game Studio**. Вся игра — один файл `index.html`, работает в браузере на телефоне и компьютере.

## Как играть
Открой `index.html` (или GitHub Pages этого репозитория). Прогресс сохраняется автоматически в браузере.

## Новое в v3.3 «Спокойная дача»
- Вредители реже: событие раз в 4–7 минут (было 45–105 секунд), первые 3 минуты после входа — без нападений, не больше 2 заражённых грядок сразу
- Жуки/тля/слизни съедают максимум 24% урожая (`BUG_CAP`), по 4% раз в 2 минуты; после обработки грядка защищена 1 час (`BUG_SAFE`)
- Вороны: −15% вместо −25%, 25 секунд, чтобы прогнать
- Подарки за ежедневный вход увеличены примерно в 1,5 раза

## Новое в v3.2 «Сад, ферма и засуха»
- Засуха больше не требует полива каждые 20 минут: созревший урожай на грядке засыхает через 20 часов (`DRY_MS`), предупреждение за 4 часа; старые сохранения получают отсрочку (`dry20`)
- В Израиле есть коровник с коровами (пастбище) и овчарня с овцами (двор), курятник доступен сразу
- Сад расширен до 17 деревьев: луг у пастбища + участок за домом, таблички «Сад»; колодец перенесён к дому
- Рыбалка на причале у озера; прогресс и уровень сохраняются

## Новое в v3.1 «Израиль — не спеша»
- В Израиле всё растёт и делается примерно в 2 раза медленнее (`tm()` ×2, рыбалка ×2) — Света объясняет это в диалоге
- По прибытии все грядки заросли сорняками (состояние `wild`); прополка — инструментом из «Улучшений»
- 3 инструмента, каждый быстрее: ручной рыхлитель → грабли → тяпка (`WT` в `src/game11.js`)
- Трактор за 10 000 монет сам ездит по полю и вскапывает свободные грядки (`tractorTick`)
- Прогресс сохраняется: старые израильские грядки один раз помечаются заросшими (`wildFix`)

## Новое в v3.0 «Дача в Израиле»

- Новая огромная локация (5152×2186): поле на 30 грядок, каменный двор на 10 теплиц, луг и полоса для сада, ряд мастерских
- Гид — Светлана (дочь Татьяны), во дворе играет Давид (ночью дома, по нажатию «Привет, бабушка!»)
- Механика засухи и капельный полив; израильские овощи, зелень, деревья, кусты, животные и блюда — по одной новинке за уровень после переезда
- Код локаций: `src/game11.js` (`applyLoc`, `ILC`, `IL_STEPS`)

## Сохранения
Прогресс хранится в браузере под ключом `dacha_v1_save` (v1.0 начинается заново). Функция `migrate()` дополняет старые сохранения новыми полями, поэтому обновления не стирают прогресс игроков — при добавлении новых полей достаточно добавить их в `newState()`.

## Разработка
Собрать `index.html`:

```bash
python3 tools/build.py
```
Исходники: `src/*.js`, `src/body.html`, `src/*.css`, картинки — `src/assets/`. Описание обновления для игроков — массив `CHANGES` в `src/game9.js`. Модули v2.0 (перенос участка, погода, праздники, рыбалка, лес, ярмарка) — `src/game10.js`.
